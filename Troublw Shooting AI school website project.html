Troubleshooting AI Demo

This demo works directly from your browser without a CGI server.

Choose a problem category

Open the site from index.html and use the same categories to see guided advice once the site is hosted with CGI support.

  • Installation or setup: Verify environment, install dependencies, and configure the correct model or API key.
  • Performance issues: Reduce request size, optimize memory usage, and monitor CPU/GPU load.
  • Poor output quality: Make prompts more explicit, add examples, and validate training data.
  • Integration errors: Check request formats, API keys, endpoints, and response codes.
  • Other: Collect logs, reproduce the issue with a minimal example, and document exact steps.
